# CrediScope – Banking Loan Portfolio Analysis

An end-to-end data analytics project using Python, SQL, and Power BI to analyze banking loan performance, approval trends, overdue loans, and default risk.

## 📌 Project Overview

CrediScope focuses on analyzing a bank's loan portfolio to understand loan performance, approval patterns, repayment status, and factors associated with default risk. The project uses Python for data cleaning and exploratory data analysis, SQL for querying and analysis, and Power BI for interactive visualization.

## 🎯 Project Objectives

- Analyze overall loan portfolio performance.
- Evaluate loan approval and rejection trends.
- Identify factors associated with loan default risk.
- Monitor overdue loans and repayment performance.
- Compare loan outcomes across loan types and customer segments.
- Build interactive dashboards for data-driven decision-making.

### 1. Portfolio Overview
- Total loan portfolio overview
- Loan status distribution
- Loan amount by loan type
- Default rate by disbursal quarter
- Key performance indicators (KPIs)

### 2. Aging & Overdue Analysis
- Overdue loan monitoring
- Days past due (DPD) analysis
- Loan repayment status
- Overdue trends across loan segments

### 3. Risk Analysis
- Default rate analysis
- Credit score analysis
- Loan-to-income ratio analysis
- Risk patterns across loan types and customer categories

### 4. Approval Analysis
- Loan approval and rejection trends
- Approval rate by loan type
- Rejection reasons
- Application status analysis

## 🚀 Project Workflow

1. **Python:** Clean the datasets, handle missing values, and perform exploratory data analysis.
2. **SQL:** Query the data to analyze loan performance, approvals, and risk indicators.
3. **Power BI:** Build interactive dashboards with KPI cards, charts, slicers, and report navigation.

## 💡 Business Value

This project helps explore loan portfolio performance, understand factors associated with default risk, monitor overdue accounts, and evaluate approval patterns to support informed lending and risk-management decisions.
